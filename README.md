# 휴가 캘린더 (ProWorkflow) 크롬 확장

ProWorkflow Power Apps의 휴가자 데이터를 월간 캘린더로 보여주는 개인용 크롬 확장입니다.
새 권한이나 앱 등록 없이, 내 브라우저에서 Power Apps가 이미 받아오는 데이터만 사용합니다.

## 설치

1. 크롬에서 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
3. 퍼즐 아이콘에서 "휴가 캘린더"를 고정

파일을 고친 뒤에는 `chrome://extensions`에서 새로고침(↻)합니다.
캘린더 화면(`calendar.*`)만 바뀐 경우에는 캘린더 탭 새로고침으로 충분합니다.

## 기능

- **월간 캘린더**: 월~금, 연속 휴가는 하나의 막대로 연결, 공휴일/공동연차는 빗금 표시
- **자동 갱신**: 캘린더를 열 때 데이터가 1시간보다 오래됐으면 Power Apps를 최소화 창으로 잠깐 열어 받아옴.
  상단 "휴가 정보 갱신" 버튼으로 수동 갱신 가능
- **부서 필터**: 왼쪽 체크박스. Teams 웹의 조직도 탭을 한 번 열면 상위 부서까지 트리로 표시
- **내 잔여 연차**: 상단 바에 잔여/부여 일수 표시 (근속연차는 있을 때만)
- 이름/부서 검색, 휴가 구분 필터, 날짜별 상세 패널

## 파일 구성

| 파일 | 역할 |
|---|---|
| `hook.js` | Power Apps 페이지(MAIN world)에서 SharePoint 커넥터 응답을 읽음. 자동 갱신 시 앱과 같은 조회 요청을 보냄 |
| `relay.js` | 페이지 → 확장 백그라운드로 메시지 전달 |
| `orgchart.js` | Teams 조직도 앱에서 부서 트리 구조만 읽음 |
| `background.js` | 수집 데이터 병합/저장, 자동 갱신 창 관리 |
| `calendar.html/js/css` | 캘린더 화면 |

## 데이터와 개인정보

- 휴가 일정: 휴가자조회 화면에서 볼 수 있는 범위와 동일 (이름, 부서, 구분, 날짜)
- 조직도: 부서 코드/이름/상위 부서만 저장. 직원 이름·연락처는 읽지 않음
- 잔여 연차: **본인 것만** 저장. 자동 갱신 시에도 본인 이메일로 필터링해서 조회
- 인증 정보는 Power Apps 페이지 메모리 안에서만 쓰고 저장하지 않음
- 모든 데이터는 이 PC의 크롬 확장 저장소에만 있고, 캘린더의 "수집 데이터 지우기"로 삭제

## 한계

- Power Apps 내부 구조(리스트 ID, 요청 형식)가 바뀌면 수집이 멈출 수 있음
- 휴가 리스트는 앱과 같이 500건까지만 조회
- 조직도는 Teams 웹(크롬)에서만 수집 가능. Teams 데스크톱 앱은 불가
