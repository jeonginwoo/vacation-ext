# 휴가 캘린더 (ProWorkflow) 크롬 확장

ProWorkflow Power Apps의 휴가자 데이터를 월간 캘린더로 보여주는 개인용 크롬 확장입니다.
새 권한이나 앱 등록 없이, 내 브라우저에서 Power Apps가 이미 받아오는 데이터만 사용합니다.

## 설치

1. 크롬에서 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
3. 퍼즐 아이콘에서 "휴가 캘린더"를 고정
4. 휴가 캘린더 → 세부정보 → **사이트 액세스**가 "특정 사이트에서" 또는 "모든 사이트에서"인지 확인
   ("클릭 시"면 수집이 되지 않고, 캘린더 상단에 안내가 표시됩니다)

파일을 고친 뒤에는 `chrome://extensions`에서 새로고침(↻)합니다.
캘린더 화면(`calendar.*`)만 바뀐 경우에는 캘린더 탭 새로고침으로 충분합니다.

## 기능

- **월간 캘린더**: 월~금, 연속 휴가는 하나의 막대로 연결, 공휴일/공동연차는 빗금 표시
- **자동 갱신**: 캘린더를 열 때 데이터가 1시간보다 오래됐으면 자동으로 받아옴. ↻ 버튼으로 수동 갱신
  - Power Apps 탭이 열려 있으면 그 탭에서 조회 (새 탭/창 없음)
  - 없거나 실패하면 현재 창에 백그라운드 탭으로 잠깐 열었다가 닫음
- **부서 필터**: 왼쪽 체크박스. Teams 웹의 조직도 탭을 한 번 열면 상위 부서까지 트리로 표시
- **내 잔여 연차**: 휴가 구분 체크박스 오른쪽에 표시. 누르면 전체 인원 연차 현황 팝업
  (부서 필터, 이름 검색, 열 정렬)
- 이름/부서 검색, 휴가 구분 필터, 날짜별 상세 패널

## 파일 구성

| 파일 | 역할 |
|---|---|
| `hook.js` | Power Apps 페이지(MAIN world)에서 SharePoint 커넥터 응답을 읽음. 갱신 시 앱과 같은 조회 요청을 보냄 |
| `relay.js` | 페이지 ↔ 확장 백그라운드 메시지 전달 |
| `orgchart.js` | Teams 조직도 앱에서 부서 트리 구조만 읽음 |
| `background.js` | 수집 데이터 병합/저장, 자동 갱신(열린 탭 재사용 / 백그라운드 탭) 관리 |
| `calendar.html/js/css` | 캘린더 화면과 연차 현황 팝업 |
| `icons/` | 확장 아이콘 |

## 데이터와 개인정보

- 휴가 일정: 휴가자조회 화면에서 볼 수 있는 범위와 동일 (이름, 부서, 구분, 날짜)
- 연차 현황: Power Apps 휴가현황 화면이 불러오는 연차 리스트 (이름, 이메일, 부여/사용/잔여)
  → 민감한 인사 정보이므로 화면 캡처 공유나 확장 배포는 하지 않음
- 조직도: 부서 코드/이름/상위 부서만 저장. 직원 이름·연락처는 읽지 않음
- 인증 정보는 Power Apps 페이지 메모리 안에서만 쓰고 저장하지 않음
- 모든 데이터는 이 PC의 크롬 확장 저장소에만 있고, 캘린더의 🗑 버튼으로 삭제

## 한계

- Power Apps 내부 구조(리스트 ID, 요청 형식)가 바뀌면 수집이 멈출 수 있음
- 리스트는 앱과 같이 500건까지만 조회
- 조직도는 Teams 웹(크롬)에서만 수집 가능. Teams 데스크톱 앱은 불가
- 완전히 보이지 않는 갱신(숨김 iframe)은 크롬이 확장 페이지 안 iframe에 확장 스크립트를 넣지 않아 불가
